# 실기기 테스트 체크리스트

배포 URL(HTTPS)로 진행하세요. 각 항목을 **iPhone Safari**와 **Android Chrome(갤럭시)** 양쪽에서, 가능하면 **브라우저 탭**과 **홈 화면에 추가한 앱** 둘 다에서 확인합니다.
결과는 O / X / 메모로 적어주세요. X가 나오면 기기, OS 버전, 영상 링크를 같이 적어주세요.

| # | 항목 | 방법 | 기대 결과 | iOS | Android |
|---|---|---|---|---|---|
| **재생** |
| 1 | 붙여넣기 버튼 | 유튜브 앱에서 "링크 복사" → 앱의 [붙여넣기] | (iOS) "붙여넣기" 말풍선이 뜨고, 누르면 곡이 로드됨 | | |
| 2 | 입력창에 직접 붙여넣기 | 입력창을 길게 눌러 붙여넣기 | 엔터를 누르지 않아도 바로 로드됨 | | |
| 3 | 링크 형식 | `youtu.be`, `shorts`, `music.youtube.com`, 공유 문구 전체 | 전부 로드됨 | | |
| 4 | 첫 재생 | ▶ 탭 | 재생됨, 영상이 전체화면으로 튀어나가지 않음(playsinline) | | |
| 5 | 스포티파이 링크 | 스포티파이 공유 링크 붙여넣기 | 미지원 안내가 뜸 | | |
| 6 | 임베드 차단 영상 | 공식 MV 몇 개 시도 | 101/150 안내 + "유튜브에서 열기" 동작 | | |
| **A-B 반복** |
| 7 | 3초 동선 | 링크 → ▶ → A → B → [−] 3번 | 3초 안에 0.85x 반복이 시작됨 | | |
| 8 | 반복 정밀도 | 박자가 뚜렷한 구간을 1~2초로 잡고 20회 반복 | B를 넘어서 들리는 소리가 거의 없음(0.1초 이내 체감). 끊김 정도 메모 | | |
| 9 | 미세 조정 | A ±0.1, B ±0.1 | A는 A부터 재생, B는 B 2초 전부터 재생해서 끝점 확인 | | |
| 10 | 시크바 | 드래그 | 놓은 위치로 이동, A-B 구간이 초록색으로 표시 | | |
| **속도** |
| 11 | 배속 칩 | 표시된 값들 | 유튜브가 반환한 값만 보임(보통 0.25~2) | | |
| 12 | **0.05 단위** | [−]로 0.95 → 0.90 → 0.85 | 하단에 "0.05 단위 배속 확인됨" 또는 "지원하지 않음" 문구. **어느 쪽이 떴는지 꼭 기록** | | |
| 13 | 음정 유지 | 0.7x | 음정은 그대로이고 느려지기만 함 | | |
| **구간/목록** |
| 14 | 구간 저장 | A-B → [+ 후렴] | 목록에 추가됨, 탭하면 그 구간 반복 | | |
| 15 | 재방문 | 앱을 완전히 닫았다가 다시 열고 곡 목록 → 곡 탭 | 구간, 배속이 복원됨 | | |
| 16 | 로컬 파일 | [파일] → mp3/m4a/mp4 | 재생, 0.05 배속, A-B 동작 | | |
| 17 | 로컬 파일 재열기 | 새로고침 → 곡 목록에서 그 파일 | 파일을 다시 고르지 않아도 재생됨 | | |
| **기타** |
| 18 | 거울 모드 | ⇋ | 영상 좌우 반전 | | |
| 19 | 화면 켜두기 | ☀ 켠 상태로 재생 후 2분간 터치 없이 둠 | 화면이 꺼지지 않음(버튼이 안 보이면 미지원 기기) | | |
| 20 | 화면 꺼짐 | 재생 중 전원 버튼 | (iOS) 재생 멈춤은 알려진 한계. 다시 켰을 때 ▶로 이어서 재생되는지 확인 | | |
| 21 | BPM 탭 | 0.8x로 재생하며 박자에 맞춰 8번 탭 | 원곡 BPM에 가까운 값(±3) | | |
| 22 | 8카운트 | "지금 위치를 1로" → 8카운트 표시 | 음악과 카운트가 맞음 | | |
| 23 | 카운트인 | 카운트인 ON → ▶ | 비프 4번(5·6·7·8) 후 재생. 무음 모드(iOS 링거 스위치)에서 비프가 들리는지도 확인 | | |
| 24 | 홈 화면 추가 | iOS: 공유 → 홈 화면에 추가 / Android: 메뉴 → 앱 설치 | 아이콘, 이름, 다크 상태바가 정상 | | |
| 25 | 공유로 열기(Android) | 앱 설치 후 유튜브 앱 → 공유 → 댄스 리플레이 | 곡이 바로 로드됨 | — | |
| 26 | 바닥에 둔 채 조작 | 폰을 바닥에 두고 서서 A/B/재생 탭 | 오터치 없이 누를 수 있는 크기인지 | | |

## 피드백으로 받고 싶은 것 (여자친구용)

- 리플레이어와 비교해서 불편한 동선 1~3개
- 가장 자주 쓰는 배속 범위(칩 구성에 반영할 예정)
- 반복할 때 끊김이 연습에 방해되는 수준인지
