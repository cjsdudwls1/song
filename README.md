# 댄스 리플레이

댄서를 위한 안무 연습용 플레이어(모바일 웹/PWA). 유튜브 링크를 붙여넣으면 바로 A-B 구간 반복, 0.05 단위 속도 조절, 구간 북마크를 쓸 수 있습니다. 내 음원/영상 파일도 열 수 있습니다.

- 유튜브는 공식 **IFrame Player API** 임베드로만 재생합니다(음원 추출 없음, 광고 제거 없음).
- 서버와 로그인이 없습니다. 데이터는 기기 안(localStorage + IndexedDB)에만 저장됩니다.

## 개발

```bash
npm install
npm run dev      # http://<PC IP>:5173 → 같은 와이파이의 폰에서 접속 가능
npm test         # 링크 파싱 / A-B 로직 / 카운트 단위 테스트
npm run build    # dist/
```

> 클립보드 읽기, Wake Lock, 서비스워커는 **HTTPS**에서만 동작합니다. 폰에서 이 기능까지 확인하려면 배포본(GitHub Pages)으로 테스트하세요.

## 기능

| 기능 | 비고 |
| --- | --- |
| 링크 붙여넣기 → 즉시 재생 | `watch?v=`, `youtu.be/`, `shorts/`, `music.youtube.com`, `m.youtube.com`, `embed/`, `live/`, 공유 문구 속 URL, `t=` 시작 시간 |
| A-B 반복 | B를 찍는 순간 반복 시작. A/B 각각 ±0.1초. rAF + 50ms 타이머로 B 지점 감시 |
| 속도 | `getAvailablePlaybackRates()` 값은 칩으로, ±0.05는 실제 적용값을 읽어 확인한 뒤 안 되면 칩 값만 사용 |
| 구간 북마크 | 인트로/1절/후렴 등의 이름으로 저장, 탭하면 그 구간 반복. ⟳ 버튼은 현재 A-B로 덮어쓰기 |
| 곡 목록 | 최근 곡과 ★ 저장한 곡. 곡마다 마지막 배속, BPM, 구간 기억 |
| 거울 모드 | 영상 좌우 반전(유튜브 컨트롤도 같이 뒤집힘) |
| 화면 켜두기 | Wake Lock API를 지원하는 브라우저에서만 버튼이 보임. 재생 시 자동 요청 |
| 카운트 | BPM 탭(배속 보정 포함), 8카운트 표시, 카운트인 5·6·7·8 비프 |
| 로컬 파일 | HTML5 media, `preservesPitch`, 최근 파일 8개는 IndexedDB에 보관해서 다시 고를 필요 없음 |
| 안드로이드 공유 | 홈 화면에 설치하면 유튜브 앱 → 공유 → "댄스 리플레이"로 바로 열림(Web Share Target. iOS는 미지원) |

디버그: `?debug`를 붙이면 `window.__dbg.player` / `__dbg.loop`에 접근할 수 있습니다. `?v=<링크 또는 ID>`로 열면 바로 로드됩니다.

## 알려진 한계

- **iOS 사파리**: 화면을 끄거나 앱을 백그라운드로 보내면 유튜브 임베드 재생이 멈춥니다(웹으로는 우회 불가). 앱 안의 ☀ 버튼(화면 켜두기)으로 대응합니다. iOS 16.4 이상, 홈 화면 앱에서는 18.4 이상이 필요합니다.
- **자동재생**: 첫 재생은 반드시 ▶를 직접 눌러야 합니다. 카운트인을 켠 상태에서 그 곡의 첫 재생이 막히면 "▶ 한 번 더" 안내가 뜹니다.
- **임베드 차단 영상(오류 101/150)**: 일부 공식 MV는 외부 재생을 막아둡니다. 안내와 "유튜브에서 열기" 버튼이 뜹니다. 가사 영상이나 다른 업로드를 쓰면 대개 됩니다.
- **반복 이음새**: 유튜브는 seek할 때 버퍼링이 생길 수 있어 B→A 전환에 짧은 끊김이 있을 수 있습니다. 로컬 파일 모드가 더 매끄럽습니다.
